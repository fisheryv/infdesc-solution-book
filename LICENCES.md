The CC BY-SA 4.0 licence applies to the compiled textbook `infdesc.pdf`, its text and figures, and any other human-readable works compiled from the source code.

Except where noted in the next paragraph, the LPPL Version 1.3c licence applies to the source code for the textbook, which consists of all the `.tex` files contained in the same directory as this file (`LICENCES.md`) and its subdirectories. A full list of the `.tex` files comprising the source code for *An Infinite Descent into Pure Mathematics* can be found in `licences/source-manifest.tex`. In the context of the LPPL Version 1.3c licence, the status of the work is 'maintained' and the Current Maintainer is [Clive Newstead](https://clive.news/tead).

In all such cases, a URI linking to the web page where the content was accessed and (where known) the code author's name or username are provided; information about how the code is licensed can be found on the linked web page.
